支持与反馈

遇到问题、想提建议，或希望加入测试，都可以发邮件联系。

发送邮件

邮箱：eric_kwoc@icloud.com。请附上系统版本、App 版本与复现步骤；如与小组件显示有关，请说明组件名称并附截图。请勿发送 API 密钥、完整项目文件或其它敏感信息。

TestFlight 测试

测试版通过 TestFlight 分发。安装后可以从 App Store 的 TestFlight 页面更新到最新构建。反馈时请注明构建号，便于对照修复。

常见问题

如何把小组件添加到主屏幕？

在 App 中创建并保存项目后，长按主屏幕空白处进入编辑状态，点左上角「+」，搜索 AnyWidgets，选择尺寸并添加，然后选择要显示的项目。

AI 功能怎么配置？

在设置中新增模型端点，填写兼容 OpenAI Chat Completions 的地址、模型名和 API 密钥。密钥保存在系统钥匙串，仅本机可用。请求直接从设备发往你填写的服务。

小组件没有刷新怎么办？

先确认项目能在 App 内正常预览；再检查组件是否声明了所需的网络来源，以及系统是否限制了后台刷新。必要时移除后重新添加小组件。

支持哪些系统？

当前支持 iOS／iPadOS 17 及以上，macOS 版本仍在开发中。
