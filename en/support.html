Support and feedback

Email us for problems, suggestions, or to join the beta.

Send email

Email: eric_kwoc@icloud.com. Include your OS version, app version, and steps to reproduce. For widget rendering issues, name the widget and attach a screenshot. Please do not send API keys, full project files, or other sensitive information.

TestFlight

Betas are distributed through TestFlight. After installing, update to the latest build from the TestFlight page in the App Store. Mention the build number when reporting issues so fixes can be matched.

Frequently asked questions

How do I add a widget to the Home Screen?

Create and save a project in the app, then long-press an empty area of the Home Screen, tap “+” in the top-left corner, search for AnyWidgets, pick a size, and choose the project to display.

How do I set up AI?

Add a model endpoint in settings with an OpenAI Chat Completions-compatible URL, model name, and API key. The key is stored in the system Keychain and stays on this device. Requests go directly from the device to the service you enter.

My widget is not refreshing

First confirm the project previews correctly in the app, then check that the widget declares the network origins it needs and that the system is not restricting background refresh. If needed, remove and re-add the widget.

Which systems are supported?

iOS and iPadOS 17 or later. The macOS version is still in development.
